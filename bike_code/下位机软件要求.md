# 上位机通信契约 · 协议 v2（整数度）

> 对应 `USER/upper/upper.c` / `upper.h` 当前实现。所有舵机字段使用整数度，**不乘以 10、不除以 10**；旧版 0.1°单位已停用。帧中没有版本字段，两端必须同步采用此约定。

上位机连接 **USART2，115200 8N1**：车端 PD6 RX、PD5 TX，双方 TX/RX 交叉连接并共地。UART7 的 ASCII 蓝牙遥控及 USART6 的二进制遥测是另外两条链路；仓库根目录 `REMOTE_PROTOCOL.md` 描述的是遥控链路，不是本文协议。

当前范围：舵机 **−90°～+90°**（负为左、正为右），后轮 **0～180 rpm**。例如右转 30°直接发送 int16 值 `30`，小端字节 `1E 00`；左转 45°发送 `-45`，小端字节 `D3 FF`。

角度直接控制**前轮转向舵机自身输出轴相对中位的角度**，不是车龙头、车把或前轮经过连杆后的实际转角。`servo=30` 表示舵机相对中位向右转向方向偏转 30°；机械传动后的车头转角由连杆几何决定，不由该字段直接指定。命令、回显和边界字段都采用这一舵机角度定义。

上电默认由遥控器控制。必须由遥控器发送 `(S,)` 切到上位机控制，再发送新的命令；`S` 是切换命令，请勿周期重发。边界查询在两种模式都可用。执行要求平衡已使能且不在重立缓冲期；否则目标清零。上位机模式超时 **100ms**，请持续每 **20～30ms** 发送完整目标命令（目标未变化也要发）；查询帧不能代替命令保活。

**CRC-8**（四条帧都用）：多项式 `0x07`，初值 `0x00`，不反转、不异或。
自检：对 `"123456789"` 算出 `0xF4`。

## 一、要实现什么

| # | 方向 | 内容 | 章节 |

| 1 | 收 | **命令帧**（8 字节）→ 校验通过后设为当前目标值 | §二 |

## 二、收：命令帧（固定 8 字节）

```
 偏移  长度  字段     类型       单位     说明
 ─────────────────────────────────────────────────────────────
  0     1   帧头1    —          —        0xAA
  1     1   帧头2    —          —        0x55
  2     2   servo    int16 小端  1°       舵机轴相对中位的目标角度，正 = 右转向
  4     2   rpm      int16 小端  r/min    电机转速，0 = 停
  6     1   crc8     —          —        覆盖字节 0..5
  7     1   帧尾     —          —        0x5A
 ─────────────────────────────────────────────────────────────
```

**要求：**

1. 找到帧头 `AA 55` → 收满 8 字节 → 查帧尾 `0x5A` → 查 CRC-8 → 查 `rpm ≥ 0`。
2. 全部通过：把 `servo`、`rpm` **限幅后**设为当前目标值，并记录"收到有效命令的时刻"。
3. 任一项不通过：丢弃该帧，不改变任何状态。
4. 丢弃一帧时，**只跳过 `AA 55` 这两个字节**，从下一个字节继续找帧头。
5. 处理必须**幂等**：同一帧收到 100 次 ≡ 收到 1 次，**不得累加**。
6. `servo`、`rpm` 超出你的量程 → 钳位，并置回显帧的 `CLAMPED` 位。

**帧样例**：

| 场景 | 8 字节 |
|---|---|
| 回中 + 停 | `AA 55 00 00 00 00 DD 5A` |
| 直行 120 rpm | `AA 55 00 00 78 00 D7 5A` |
| 舵机右 30° / 120 rpm | `AA 55 1E 00 78 00 74 5A` |
| 舵机左 45° / 180 rpm | `AA 55 D3 FF B4 00 1A 5A` |

## 三、收：边界查询帧（固定 4 字节）

```
 偏移  长度  字段     类型   说明
 ──────────────────────────────────────────
  0     1   帧头1    —      0xAA
  1     1   帧头2    —      0x57
  2     1   crc8     —      覆盖字节 0..1
  3     1   帧尾     —      0x5A
 ──────────────────────────────────────────
```

**要求**：CRC 通过 → **立即回一帧边界帧**（§五）。此帧不改变任何目标值。

**帧样例**：`AA 57 38 5A`

## 四、发：回显帧（固定 9 字节）

```
 偏移  长度  字段     类型       单位     说明
 ─────────────────────────────────────────────────────────────
  0     1   帧头1    —          —        0xAA
  1     1   帧头2    —          —        0x55
  2     2   servo    int16 小端  1°       当前采用的软件角度（超时清零后 = 0）
  4     2   rpm      int16 小端  r/min    当前采用的软件转速指令（超时清零后 = 0）
  6     1   status   u8         —        见下表
  7     1   crc8     —          —        覆盖字节 0..6
  8     1   帧尾     —          —        0x5A
 ─────────────────────────────────────────────────────────────
```

**`status` 位：**

| 位 | 名称 | 置 1 条件 |
|---|---|---|
| 0 | `LINK_OK` | 最近一个超时周期内收到过有效命令帧 |
| 1 | `TIMEOUT_SEEN` | 自上次上电以来曾进入过安全态（置 1 后保持到复位） |
| 2 | `MOTOR_EN` | 电机使能中 |
| 3 | `MEASURED` | 回显值是实测值（有舵机反馈 / 编码器）；无传感器填 0 |
| 4 | `CLAMPED` | 本帧回显的值被限幅过 |
| 5–7 | — | 填 0 |

**要求：**

1. **每 100 ms 一帧**。
2. `servo`、`rpm` 或 `status` 任一变化 → **立即补发一帧**。
3. 无传感器时填内部实际采用的值，并把 `MEASURED` 填 0。

当前实现 `MEASURED=0`：角度是限速后的软件输出，转速是最终电机指令，不是传感器实测值。角度回显与命令采用相同单位和方向，达到目标前可能因转向斜坡而不同。

**帧样例**：

| 场景 | 9 字节 |
|---|---|
| 执行中（右 30°、120 rpm、链路正常、电机使能） | `AA 55 1E 00 78 00 05 50 5A` |
| 超时后（0、0、曾进安全态） | `AA 55 00 00 00 00 02 13 5A` |

## 五、发：边界帧（固定 12 字节）

```
 偏移  长度  字段        类型       单位     说明
 ─────────────────────────────────────────────────────────────
  0     1   帧头1       —          —        0xAA
  1     1   帧头2       —          —        0x56
  2     2   servo_min   int16 小端  1°       可用最小舵机角（左极限，一般 < 0）
  4     2   servo_max   int16 小端  1°       可用最大舵机角（右极限，一般 > 0）
  6     2   rpm_min     uint16 小端 r/min    最小可稳转速；0 = 未提供
  8     2   rpm_max     uint16 小端 r/min    最大可用转速；0 = 未提供
 10     1   crc8        —          —        覆盖字节 0..9
 11     1   帧尾        —          —        0x5A
 ─────────────────────────────────────────────────────────────
```

**要求：**

1. 填**你实际会接受的量程**（就是 §二 里做限幅用的那两个数）。
2. 必须保证 **`servo_max` 是往右的极限**；舵机装反时在固件内部取反。
3. 未标定时填当前保守值；全部填 0 表示"未提供"。
4. 收到边界查询帧（§三）时回一帧；上电后也可主动发一次。

**帧样例**：

| 场景 | 12 字节 |
|---|---|
| 当前车端：舵机 ±90°、rpm_min 未标定、rpm_max=180 | `AA 56 A6 FF 5A 00 00 00 B4 00 A9 5A` |
| 未提供（全 0） | `AA 56 00 00 00 00 00 00 00 00 B8 5A` |

## 六、超时保护

**判据**：距上次收到**有效命令帧**的时间 > 超时值。

**动作**：`servo = 0`、`rpm = 0`（回中 + 停），置 `TIMEOUT_SEEN`；收到新的有效命令帧后自动恢复。

**超时值**（当前 `UPPER_TIMEOUT_MS=100u`，编译期可覆盖；下表其他档位仅供配置参考，并非运行时切换）：

| 档 | 超时值 | 上位机发送间隔上限 |
|---|---|---|
| bench（台架 / 低速调试） | 500 ms | ≤ 166 ms |
| slow（低速路测 ≤1.5 m/s） | 200 ms | ≤ 66 ms |
| normal（正常行驶，默认） | 100 ms | ≤ 33 ms |

## 七、上电默认

| 项 | 要求 |
|---|---|
| 舵机 | 中位（`servo = 0`） |
| 电机 | 不使能 |
| 目标值 | `servo = 0`、`rpm = 0` |
| 是否等待握手 | 无握手；先由遥控器 `(S,)` 切入上位机模式，平衡使能且非重立期间才能执行新命令 |
