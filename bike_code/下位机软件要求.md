# 下位机软件要求 · 协议 v2

> 本文只写**要实现什么**。四条帧 + 一条超时规则 + 上电默认态。

**CRC-8**（四条帧都用）：多项式 `0x07`，初值 `0x00`，不反转、不异或。
自检：对 `"123456789"` 算出 `0xF4`。

---

## 一、要实现什么

| # | 方向 | 内容 | 章节 |
|---|---|---|---|
| 1 | 收 | **命令帧**（8 字节）→ 校验通过后设为当前目标值 | §二 |
| 2 | 收 | **边界查询帧**（4 字节）→ 回一帧边界帧 | §三 |
| 3 | 发 | **回显帧**（9 字节）：每 100 ms 一帧，值/状态变化时立即补发 | §四 |
| 4 | 发 | **边界帧**（12 字节）：收到查询帧时回 | §五 |
| 5 | 内部 | **超时保护**：超过超时时间没收到有效命令帧 → 目标清零 | §六 |
| 6 | 内部 | **上电默认**：舵机中位、电机不使能 | §七 |

---

## 二、收：命令帧（固定 8 字节）

```
 偏移  长度  字段     类型       单位     说明
 ─────────────────────────────────────────────────────────────
  0     1   帧头1    —          —        0xAA
  1     1   帧头2    —          —        0x55
  2     2   servo    int16 小端  0.1°     舵机绝对角度，0 = 中位，正 = 右
  4     2   rpm      int16 小端  r/min    电机转速，0 = 停
  6     1   crc8     —          —        覆盖字节 0..5
  7     1   帧尾     —          —        0x5A
 ─────────────────────────────────────────────────────────────
```

**要求：**

1. 找到帧头 `AA 55` → 收满 8 字节 → 查帧尾 `0x5A` → 查 CRC-8 → 查 `rpm ≥ 0`。
2. 全部通过：把 `servo`、`rpm` **限幅后**设为当前目标值，并记录"收到有效命令的时刻"。
3. 任一项不通过：丢弃该帧，不改变任何状态。
4. 丢弃一帧时，**只跳过 `AA 55` 这两个字节**，从下一个字节继续找帧头。
5. 处理必须**幂等**：同一帧收到 100 次 ≡ 收到 1 次，**不得累加**。
6. `servo`、`rpm` 超出你的量程 → 钳位，并置回显帧的 `CLAMPED` 位。

**帧样例**：

| 场景 | 8 字节 |
|---|---|
| 回中 + 停 | `AA 55 00 00 00 00 DD 5A` |
| 直行 1500 rpm | `AA 55 00 00 DC 05 80 5A` |
| 舵机右 12.3° / 1500 rpm | `AA 55 7B 00 DC 05 38 5A` |
| 舵机左 8.5° / 2000 rpm | `AA 55 AB FF D0 07 2C 5A` |

## 三、收：边界查询帧（固定 4 字节）

```
 偏移  长度  字段     类型   说明
 ──────────────────────────────────────────
  0     1   帧头1    —      0xAA
  1     1   帧头2    —      0x57
  2     1   crc8     —      覆盖字节 0..1
  3     1   帧尾     —      0x5A
 ──────────────────────────────────────────
```

**要求**：CRC 通过 → **立即回一帧边界帧**（§五）。此帧不改变任何目标值。

**帧样例**：`AA 57 38 5A`

## 四、发：回显帧（固定 9 字节）

```
 偏移  长度  字段     类型       单位     说明
 ─────────────────────────────────────────────────────────────
  0     1   帧头1    —          —        0xAA
  1     1   帧头2    —          —        0x55
  2     2   servo    int16 小端  0.1°     当前生效的舵机角度（超时清零后 = 0）
  4     2   rpm      int16 小端  r/min    当前转速（超时清零后 = 0）
  6     1   status   u8         —        见下表
  7     1   crc8     —          —        覆盖字节 0..6
  8     1   帧尾     —          —        0x5A
 ─────────────────────────────────────────────────────────────
```

**`status` 位：**

| 位 | 名称 | 置 1 条件 |
|---|---|---|
| 0 | `LINK_OK` | 最近一个超时周期内收到过有效命令帧 |
| 1 | `TIMEOUT_SEEN` | 自上次上电以来曾进入过安全态（置 1 后保持到复位） |
| 2 | `MOTOR_EN` | 电机使能中 |
| 3 | `MEASURED` | 回显值是实测值（有舵机反馈 / 编码器）；无传感器填 0 |
| 4 | `CLAMPED` | 本帧回显的值被限幅过 |
| 5–7 | — | 填 0 |

**要求：**

1. **每 100 ms 一帧**。
2. `servo`、`rpm` 或 `status` 任一变化 → **立即补发一帧**。
3. 无传感器时填内部实际采用的值，并把 `MEASURED` 填 0。

**帧样例**：

| 场景 | 9 字节 |
|---|---|
| 执行中（右 12.3°、1500 rpm、链路正常、电机使能） | `AA 55 7B 00 DC 05 05 B3 5A` |
| 超时后（0、0、曾进安全态） | `AA 55 00 00 00 00 02 13 5A` |

## 五、发：边界帧（固定 12 字节）

```
 偏移  长度  字段        类型       单位     说明
 ─────────────────────────────────────────────────────────────
  0     1   帧头1       —          —        0xAA
  1     1   帧头2       —          —        0x56
  2     2   servo_min   int16 小端  0.1°     可用最小舵机角（左极限，一般 < 0）
  4     2   servo_max   int16 小端  0.1°     可用最大舵机角（右极限，一般 > 0）
  6     2   rpm_min     uint16 小端 r/min    最小可稳转速；0 = 未提供
  8     2   rpm_max     uint16 小端 r/min    最大可用转速；0 = 未提供
 10     1   crc8        —          —        覆盖字节 0..9
 11     1   帧尾        —          —        0x5A
 ─────────────────────────────────────────────────────────────
```

**要求：**

1. 填**你实际会接受的量程**（就是 §二 里做限幅用的那两个数）。
2. 必须保证 **`servo_max` 是往右的极限**；舵机装反时在固件内部取反。
3. 未标定时填当前保守值；全部填 0 表示"未提供"。
4. 收到边界查询帧（§三）时回一帧；上电后也可主动发一次。

**帧样例**：

| 场景 | 12 字节 |
|---|---|
| 舵机 ±55.0°、转速 100…3000 rpm | `AA 56 DA FD 26 02 64 00 B8 0B 7D 5A` |
| 未提供（全 0） | `AA 56 00 00 00 00 00 00 00 00 B8 5A` |

## 六、超时保护

**判据**：距上次收到**有效命令帧**的时间 > 超时值。

**动作**：`servo = 0`、`rpm = 0`（回中 + 停），置 `TIMEOUT_SEEN`；收到新的有效命令帧后自动恢复。

**超时值**（选一档，编译期常量或运行时可配）：

| 档 | 超时值 | 上位机发送间隔上限 |
|---|---|---|
| bench（台架 / 低速调试） | 500 ms | ≤ 166 ms |
| slow（低速路测 ≤1.5 m/s） | 200 ms | ≤ 66 ms |
| normal（正常行驶，默认） | 100 ms | ≤ 33 ms |

---

## 七、上电默认

| 项 | 要求 |
|---|---|
| 舵机 | 中位（`servo = 0`） |
| 电机 | 不使能 |
| 目标值 | `servo = 0`、`rpm = 0` |
| 是否等待握手 | 不等待，收到合法帧即可执行 |
